# 草稿同步故障修复（2026-10-28）

用户反馈 CSDN HTTP 400“博主不存在”、搜狐号编辑器已有内容、头条号标题超过 30 字。修复构建完成后，用户重新加载扩展并使用真实账号重试，明确反馈“已重试，三个都成功”。此验收来自用户反馈；自动化回归使用隔离页面和模拟接口。

## CSDN

- 官方创作中心存在当前账号，网页编辑器能返回保存成功提示，不能将原错误直接解释为用户没有博客。
- 当前主脚本来自 `csdnimg.cn/release/mpfev3/`，旧解析器未允许此域名，且未识别 `headers["X-Ca-Key"] = ...`。补齐域名、host permission 和赋值格式，优先读取创作中心主脚本，避免选择共享旧 SDK。
- 保存请求从 `mp.csdn.net` 页面 MAIN world 发往同站 `bizapi.csdn.net`，使用浏览器会话；Content-Type 与当前官方编辑器一致。签名在扩展中生成，不把签名密钥传入页面，不记录密钥或 Cookie。
- 严格限定草稿路径、POST、`status: 2`、空 `article_id`，禁止发布或更新已有文章。响应丢失不重试写入；仅明确的网关签名拒绝允许刷新签名后重试一次。
- 同时修正签名来源和请求上下文，没有单独隔离证明哪一项导致原 HTTP 400，不能称其中一个假设为唯一根因。

## 搜狐号

新建页面会自动恢复上次草稿，出现“已从草稿箱中恢复 撤销”，触发原有防覆盖保护。现在仅在新建路径内发现该明确提示时点击其“撤销”，确认标题、正文变空后再导入。没有入口、撤销后仍有内容、账号禁用存草稿时继续停止，不直接清空已有文章或删除平台存储。

隔离浏览器覆盖恢复入口、不相关撤销、撤销无效、旧正文保护、全文校验和只点击存草稿。用户实测成功，更新此前“未实名账号无法验证保存”的历史状态。

## 头条号

新增独立“头条号标题”输入框，显示长度并在提交前校验 2–30 字。用户修改的短标题经 `platformTitles.toutiao` 传给后台，只影响头条号。支持 front-matter `platforms.toutiao.title` 默认值，界面填写值优先；切换文件重置。重试失败平台时保留短标题，不重复同步已成功平台。
